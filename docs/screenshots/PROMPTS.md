# Mockup prompts for ChatGPT

One prompt per screenshot. For each: start a new ChatGPT chat, upload the screenshot named in
the heading, paste the prompt below it, and save the result under the "Save as" name in
`docs/assets/`. The README uses WebP, so hand the PNGs back to be converted.

Check every result against the original screenshot before using it. Image models sometimes
rewrite small UI text (card titles, counts, labels). If any text has changed, generate again.
